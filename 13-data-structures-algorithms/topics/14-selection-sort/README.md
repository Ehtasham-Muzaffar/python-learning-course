# Selection sort

**Purpose and use:** Selection sort repeatedly selects the smallest remaining item; it is simple but uses O(n?) comparisons.

## Understand the project

This project contains a complete, small implementation of **Selection sort** in `main.py`. Trace the data structure or algorithm, inspect its output, then alter the input to test the edge cases in the practice task.
