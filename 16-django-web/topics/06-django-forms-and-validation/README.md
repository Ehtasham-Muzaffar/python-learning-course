# Django forms and validation

**Purpose and use:** Forms parse and validate incoming input, returning cleaned data only after declared field and cross-field rules pass.

## Project walkthrough

This is a complete runnable Django example. The project uses explicit, in-memory development settings so it can demonstrate **Django forms and validation** without requiring a deployed site or real database. Read each statement, change a safe input, and inspect the response or validation result.

## Run

Install the optional Django dependency and run from the repository root:

```bash
python 16-django-web/topics/06-django-forms-and-validation/main.py
```

## Practice

Extend the example with a small automated test. Keep secrets in environment/deployment configuration and do not expose Django's development server to the public internet.
