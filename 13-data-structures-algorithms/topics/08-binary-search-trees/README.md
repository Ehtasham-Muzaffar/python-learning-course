# Binary search trees

**Purpose and use:** A binary search tree stores smaller values left and larger values right, supporting ordered search when reasonably balanced.

## Understand the project

This project contains a complete, small implementation of **Binary search trees** in `main.py`. Trace the data structure or algorithm, inspect its output, then alter the input to test the edge cases in the practice task.

## Run

```bash
python 13-data-structures-algorithms/topics/08-binary-search-trees/main.py
```

Core Python only.
