# Django URL routing

**Purpose and use:** URL patterns map paths to named view functions. Named routes are easier to reverse and refactor than hard-coded URLs.

## Project walkthrough

This is a complete runnable Django example. The project uses explicit, in-memory development settings so it can demonstrate **Django URL routing** without requiring a deployed site or real database. Read each statement, change a safe input, and inspect the response or validation result.

## Run

Install the optional Django dependency and run from the repository root:

```bash
python 16-django-web/topics/02-django-url-routing/main.py
```

## Practice

Extend the example with a small automated test. Keep secrets in environment/deployment configuration and do not expose Django's development server to the public internet.
