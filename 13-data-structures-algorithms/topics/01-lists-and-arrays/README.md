# Lists and arrays

**Purpose and use:** Use an ordered dynamic array when iteration, append, and indexed access are common. Python lists are suitable general-purpose sequences.

## Understand the project

This project contains a complete, small implementation of **Lists and arrays** in `main.py`. Trace the data structure or algorithm, inspect its output, then alter the input to test the edge cases in the practice task.

## Run

```bash
python 13-data-structures-algorithms/topics/01-lists-and-arrays/main.py
```

Core Python only.

## Practice

Test an empty input, a one-item input, duplicates where supported, and the normal case. Compare the result with a trusted Python built-in when one exists.
