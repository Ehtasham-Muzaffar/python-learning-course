# Python built-in modules

**Purpose and use:** The standard library includes modules for paths, dates, JSON, mathematics, statistics, and more.

## Project walkthrough

This folder is a self-contained project for **Python built-in modules**. Open `main.py` and trace each statement from its input to its result. The example uses small values so you can edit them and observe how the concept behaves.

## Run

From the repository root:

```bash
python 09-python-modules/topics/02-python-built-in-modules/main.py
```

## Practice

Predict the result, change one input, rerun the project, and explain the difference. Add one boundary or invalid-input case before moving to the next topic.
