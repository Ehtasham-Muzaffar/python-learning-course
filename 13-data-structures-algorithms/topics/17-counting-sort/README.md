# Counting sort

**Purpose and use:** Counting sort counts integer keys and runs in O(n+k); use it only when the key range k is reasonably small.

## Understand the project

This project contains a complete, small implementation of **Counting sort** in `main.py`. Trace the data structure or algorithm, inspect its output, then alter the input to test the edge cases in the practice task.

## Run

```bash
python 13-data-structures-algorithms/topics/17-counting-sort/main.py
```

Core Python only.
