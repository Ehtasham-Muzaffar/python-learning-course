# Binary search

**Purpose and use:** Binary search halves a sorted search range for O(log n) lookup; the input must already be sorted.

## Understand the project

This project contains a complete, small implementation of **Binary search** in `main.py`. Trace the data structure or algorithm, inspect its output, then alter the input to test the edge cases in the practice task.

## Run

```bash
python 13-data-structures-algorithms/topics/12-binary-search/main.py
```

Core Python only.
