# Hash tables

**Purpose and use:** Hash tables map keys to values for average-case fast lookup; Python dictionaries and sets implement this pattern.

## Understand the project

This project contains a complete, small implementation of **Hash tables** in `main.py`. Trace the data structure or algorithm, inspect its output, then alter the input to test the edge cases in the practice task.

## Run

```bash
python 13-data-structures-algorithms/topics/05-hash-tables/main.py
```

Core Python only.
