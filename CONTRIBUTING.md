# Contributing

Thanks for helping make this free Python, data science, and machine learning course more useful. Contributions of all sizes are welcome.

## Ways to contribute

- Improve lesson clarity, accessibility, or correctness.
- Add an exercise, test, or beginner-friendly explanation.
- Report a reproducible bug or suggest a course improvement in an issue.
- Review a pull request with constructive, specific feedback.

## Pull request checklist

1. Open an issue first for substantial changes; small typo and bug fixes can go directly to a pull request.
2. Keep each pull request focused and explain the learner benefit.
3. For lessons, keep the step-by-step `README.md` accurate and make the paired `lesson.py` reproducible.
4. Use deterministic, small examples that run without external datasets where practical. Do not commit credentials or generated model files.
5. Run `ruff check .` and `pytest` for relevant changes. Mention any checks you could not run.

By contributing, you agree that your contributions are provided under this repository's MIT license.
