# Python output

**Purpose and use:** Use `print` to show a result in a terminal. Functions should usually return values so other code can reuse their results.

## Project walkthrough

This folder is a self-contained project for **Python output**. Open `main.py` and trace each statement from its input to its result. The example uses small values so you can edit them and observe how the concept behaves.

## Run

From the repository root:

```bash
python 06-python-language/topics/05-python-output/main.py
```

## Practice

Predict the result, change one input, rerun the project, and explain the difference. Add one boundary or invalid-input case before moving to the next topic.
