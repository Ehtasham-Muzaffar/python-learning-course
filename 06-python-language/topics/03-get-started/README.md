# Get started

**Purpose and use:** Verify the Python interpreter and execute a script before installing libraries. This confirms your command line is using the Python version you expect.

## Project walkthrough

This folder is a self-contained project for **Get started**. Open `main.py` and trace each statement from its input to its result. The example uses small values so you can edit them and observe how the concept behaves.

## Run

From the repository root:

```bash
python 06-python-language/topics/03-get-started/main.py
```

## Practice

Predict the result, change one input, rerun the project, and explain the difference. Add one boundary or invalid-input case before moving to the next topic.
