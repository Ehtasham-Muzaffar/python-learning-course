# Python regular expressions

**Purpose and use:** Regular expressions match text patterns. Prefer simple string operations when a regex would be harder to maintain.

## Project walkthrough

This folder is a self-contained project for **Python regular expressions**. Open `main.py` and trace each statement from its input to its result. The example uses small values so you can edit them and observe how the concept behaves.

## Run

From the repository root:

```bash
python 06-python-language/topics/30-python-regular-expressions/main.py
```

## Practice

Predict the result, change one input, rerun the project, and explain the difference. Add one boundary or invalid-input case before moving to the next topic.
