# Python magic methods

**Purpose and use:** Magic methods implement Python protocols so custom values work with `str`, equality, or built-ins.

## Project walkthrough

This folder is a self-contained project for **Python magic methods**. Open `main.py` and trace each statement from its input to its result. The example uses small values so you can edit them and observe how the concept behaves.

## Run

From the repository root:

```bash
python 07-python-oop/topics/07-python-magic-methods/main.py
```

## Practice

Predict the result, change one input, rerun the project, and explain the difference. Add one boundary or invalid-input case before moving to the next topic.
