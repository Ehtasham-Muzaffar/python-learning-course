# Python if else

**Purpose and use:** Conditional branches select behavior based on data or business rules. Make boundary conditions explicit.

## Project walkthrough

This folder is a self-contained project for **Python if else**. Open `main.py` and trace each statement from its input to its result. The example uses small values so you can edit them and observe how the concept behaves.

## Run

From the repository root:

```bash
python 06-python-language/topics/18-python-if-else/main.py
```

## Practice

Predict the result, change one input, rerun the project, and explain the difference. Add one boundary or invalid-input case before moving to the next topic.
