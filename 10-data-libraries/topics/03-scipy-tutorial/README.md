# SciPy tutorial

**Purpose and use:** SciPy contains tested scientific algorithms for statistics, optimization, sparse data, and signal processing. Interpret statistical tests with design and assumptions in mind.

## Project walkthrough

This folder is a self-contained project for **SciPy tutorial**. Open `main.py` and trace each statement from its input to its result. The example uses small values so you can edit them and observe how the concept behaves.

## Run

From the repository root:

```bash
python 10-data-libraries/topics/03-scipy-tutorial/main.py
```

## Practice

Predict the result, change one input, rerun the project, and explain the difference. Add one boundary or invalid-input case before moving to the next topic.
