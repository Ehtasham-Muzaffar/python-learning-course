# Python match

**Purpose and use:** Structural pattern matching dispatches over known cases in Python 3.10+. Use it when explicit alternatives make the flow easier to read.

## Project walkthrough

This folder is a self-contained project for **Python match**. Open `main.py` and trace each statement from its input to its result. The example uses small values so you can edit them and observe how the concept behaves.

## Run

From the repository root:

```bash
python 06-python-language/topics/19-python-match/main.py
```

## Practice

Predict the result, change one input, rerun the project, and explain the difference. Add one boundary or invalid-input case before moving to the next topic.
