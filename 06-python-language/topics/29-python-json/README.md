# Python JSON

**Purpose and use:** JSON exchanges structured text with services and files. Parse it, then validate fields before relying on external data.

## Project walkthrough

This folder is a self-contained project for **Python JSON**. Open `main.py` and trace each statement from its input to its result. The example uses small values so you can edit them and observe how the concept behaves.

## Run

From the repository root:

```bash
python 06-python-language/topics/29-python-json/main.py
```

## Practice

Predict the result, change one input, rerun the project, and explain the difference. Add one boundary or invalid-input case before moving to the next topic.
