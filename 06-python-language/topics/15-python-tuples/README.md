# Python tuples

**Purpose and use:** Tuples group ordered values that should not be reassigned, such as coordinates or a fixed record.

## Project walkthrough

This folder is a self-contained project for **Python tuples**. Open `main.py` and trace each statement from its input to its result. The example uses small values so you can edit them and observe how the concept behaves.

## Run

From the repository root:

```bash
python 06-python-language/topics/15-python-tuples/main.py
```

## Practice
