# Python comments

**Purpose and use:** Comments explain intent, assumptions, or a non-obvious choice. Use docstrings for public functions and keep comments more informative than the code.

## Project walkthrough

This folder is a self-contained project for **Python comments**. Open `main.py` and trace each statement from its input to its result. The example uses small values so you can edit them and observe how the concept behaves.

## Run

From the repository root:

```bash
python 06-python-language/topics/06-python-comments/main.py
```

## Practice

Predict the result, change one input, rerun the project, and explain the difference. Add one boundary or invalid-input case before moving to the next topic.
