# Python user input

**Purpose and use:** User input arrives as text and should be validated before conversion. This non-interactive example demonstrates the same conversion safely.

## Project walkthrough

This folder is a self-contained project for **Python user input**. Open `main.py` and trace each statement from its input to its result. The example uses small values so you can edit them and observe how the concept behaves.

## Run

From the repository root:

```bash
python 06-python-language/topics/35-python-user-input/main.py
```

## Practice

Predict the result, change one input, rerun the project, and explain the difference. Add one boundary or invalid-input case before moving to the next topic.
