# Python cmath module

**Purpose and use:** Use cmath when a mathematical result may be complex, such as the square root of a negative number.

## Project walkthrough

This folder is a self-contained project for **Python cmath module**. Open `main.py` and trace each statement from its input to its result. The example uses small values so you can edit them and observe how the concept behaves.

## Run

From the repository root:

```bash
python 09-python-modules/topics/07-python-cmath-module/main.py
```
