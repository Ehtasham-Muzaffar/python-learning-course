# Python lists

**Purpose and use:** Lists store ordered, mutable sequences and allow duplicates. Use them for observations that need ordering or updates.

## Project walkthrough

This folder is a self-contained project for **Python lists**. Open `main.py` and trace each statement from its input to its result. The example uses small values so you can edit them and observe how the concept behaves.

## Run

From the repository root:

```bash
python 06-python-language/topics/14-python-lists/main.py
```
