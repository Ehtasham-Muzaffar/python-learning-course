# Bubble sort

**Purpose and use:** Bubble sort repeatedly swaps adjacent out-of-order values; its O(n?) runtime makes it an educational, not production, choice.

## Understand the project

This project contains a complete, small implementation of **Bubble sort** in `main.py`. Trace the data structure or algorithm, inspect its output, then alter the input to test the edge cases in the practice task.

## Run

```bash
python 13-data-structures-algorithms/topics/13-bubble-sort/main.py
```

Core Python only.

## Practice

Test an empty input, a one-item input, duplicates where supported, and the normal case. Compare the result with a trusted Python built-in when one exists.
