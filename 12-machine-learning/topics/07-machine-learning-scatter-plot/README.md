# Machine learning scatter plot

**Purpose and use:** Plot pairs of numeric features to inspect possible relationships; visual association is not evidence of causation.

## Project walkthrough

This mini-project focuses on **Machine learning scatter plot**. Read `main.py` from top to bottom: identify the input, the transformation or plot, and the output. Change one example value and rerun it to check your understanding.

## Run

From the repository root:

```bash
python 12-machine-learning/topics/07-machine-learning-scatter-plot/main.py
```

Install core requirements with `python -m pip install -r requirements.txt`.
