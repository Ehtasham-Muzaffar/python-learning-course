# Pandas tutorial

**Purpose and use:** Pandas provides labeled Series and DataFrames for inspecting, joining, cleaning, and aggregating tabular data.

## Project walkthrough

This folder is a self-contained project for **Pandas tutorial**. Open `main.py` and trace each statement from its input to its result. The example uses small values so you can edit them and observe how the concept behaves.

## Run

From the repository root:

```bash
python 10-data-libraries/topics/02-pandas-tutorial/main.py
```

## Practice

Predict the result, change one input, rerun the project, and explain the difference. Add one boundary or invalid-input case before moving to the next topic.
