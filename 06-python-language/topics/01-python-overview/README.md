# Python overview

**Purpose and use:** Python is a readable general-purpose language used for automation, web services, data analysis, and machine learning. Use it when its ecosystem and clear syntax fit the task.

## Project walkthrough

This folder is a self-contained project for **Python overview**. Open `main.py` and trace each statement from its input to its result. The example uses small values so you can edit them and observe how the concept behaves.

## Run

From the repository root:

```bash
python 06-python-language/topics/01-python-overview/main.py
```

## Practice

Predict the result, change one input, rerun the project, and explain the difference. Add one boundary or invalid-input case before moving to the next topic.
