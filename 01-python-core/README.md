# Phase 1: Modern Python Core

**Goal:** Build the Python foundations needed to write and understand data science code.

Start here if you are new to Python. Each lesson guide explains the ideas first; the paired script demonstrates them in runnable code.

## Learning path

1. [Set up Python and run your first program](01-environment-and-first-program/README.md) · [Script](01-environment-and-first-program/lesson.py)
2. [Understand types and data structures](02-types-and-data-structures/README.md) · [Script](02-types-and-data-structures/lesson.py)
3. [Use conditions, loops, and exceptions](03-control-flow-and-iteration/README.md) · [Script](03-control-flow-and-iteration/lesson.py)
4. [Write reusable functions and modules](04-functions-and-modules/README.md) · [Script](04-functions-and-modules/lesson.py)
5. [Model data with classes and dataclasses](05-classes-and-oop/README.md) · [Script](05-classes-and-oop/lesson.py)

**Finish line:** You can create an isolated environment, represent data with built-in types, transform it with control flow, and organize logic into functions and small classes.
