# Categorical data preprocessing

**Purpose and use:** Encode nominal categories rather than assigning arbitrary numeric order. Keep encoders in a training pipeline.

## Project walkthrough

This mini-project focuses on **Categorical data preprocessing**. Read `main.py` from top to bottom: identify the input, the transformation or plot, and the output. Change one example value and rerun it to check your understanding.

## Run

From the repository root:

```bash
python 12-machine-learning/topics/18-categorical-data-preprocessing/main.py
```

Install core requirements with `python -m pip install -r requirements.txt`.
