# Python PIP

**Purpose and use:** Use `python -m pip` so the installer targets the active interpreter; record third-party packages in a requirements file.

## Project walkthrough

This folder is a self-contained project for **Python PIP**. Open `main.py` and trace each statement from its input to its result. The example uses small values so you can edit them and observe how the concept behaves.

## Run

From the repository root:

```bash
python 09-python-modules/topics/08-python-pip/main.py
```
