# Python while loops

**Purpose and use:** A while loop repeats until a condition changes. Ensure every path makes progress toward stopping.

## Project walkthrough

This folder is a self-contained project for **Python while loops**. Open `main.py` and trace each statement from its input to its result. The example uses small values so you can edit them and observe how the concept behaves.

## Run

From the repository root:

```bash
python 06-python-language/topics/20-python-while-loops/main.py
```
