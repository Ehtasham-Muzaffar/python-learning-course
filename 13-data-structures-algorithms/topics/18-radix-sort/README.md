# Radix sort

**Purpose and use:** Radix sort processes integer digits in stable passes; runtime depends on digit count and chosen base.

## Understand the project

This project contains a complete, small implementation of **Radix sort** in `main.py`. Trace the data structure or algorithm, inspect its output, then alter the input to test the edge cases in the practice task.
