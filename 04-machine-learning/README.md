# Phase 4: Applied Machine Learning

**Goal:** Build honest, reproducible Scikit-Learn workflows for supervised and unsupervised learning.

Learn to split and preprocess data safely, fit regression and classification baselines, explore clusters, measure generalization, and tune models without using the test set as a shortcut.

## Learning path

1. [Split data and build preprocessing pipelines](01-train-test-split-and-preprocessing/README.md) · [Script](01-train-test-split-and-preprocessing/lesson.py)
2. [Predict continuous values with regression](02-regression/README.md) · [Script](02-regression/lesson.py)
3. [Predict categories with classification](03-classification/README.md) · [Script](03-classification/lesson.py)
4. [Explore unlabeled groups with clustering](04-clustering/README.md) · [Script](04-clustering/lesson.py)
5. [Evaluate models with cross-validation](05-model-evaluation-and-cross-validation/README.md) · [Script](05-model-evaluation-and-cross-validation/lesson.py)
6. [Tune hyperparameters responsibly](06-hyperparameter-tuning/README.md) · [Script](06-hyperparameter-tuning/lesson.py)

**Finish line:** You can build a pipeline, choose an appropriate metric, evaluate unseen data, and explain where model estimates may fail.
