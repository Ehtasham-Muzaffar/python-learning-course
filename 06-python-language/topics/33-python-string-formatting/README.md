# Python string formatting

**Purpose and use:** F-strings format values directly and support numeric precision for readable reports.

## Project walkthrough

This folder is a self-contained project for **Python string formatting**. Open `main.py` and trace each statement from its input to its result. The example uses small values so you can edit them and observe how the concept behaves.

## Run

From the repository root:

```bash
python 06-python-language/topics/33-python-string-formatting/main.py
```
