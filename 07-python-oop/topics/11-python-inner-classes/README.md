# Python inner classes

**Purpose and use:** A nested class can scope a tightly coupled helper, but a module-level class is usually easier to reuse and test.

## Project walkthrough

This folder is a self-contained project for **Python inner classes**. Open `main.py` and trace each statement from its input to its result. The example uses small values so you can edit them and observe how the concept behaves.

## Run

From the repository root:

```bash
python 07-python-oop/topics/11-python-inner-classes/main.py
```

## Practice

Predict the result, change one input, rerun the project, and explain the difference. Add one boundary or invalid-input case before moving to the next topic.
