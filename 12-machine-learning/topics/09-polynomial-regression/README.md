# Polynomial regression

**Purpose and use:** Polynomial features let a linear estimator model curvature. Increasing degree can overfit, so select it with training-only validation.

## Project walkthrough

This mini-project focuses on **Polynomial regression**. Read `main.py` from top to bottom: identify the input, the transformation or plot, and the output. Change one example value and rerun it to check your understanding.

## Run

From the repository root:

```bash
python 12-machine-learning/topics/09-polynomial-regression/main.py
```

Install core requirements with `python -m pip install -r requirements.txt`.
