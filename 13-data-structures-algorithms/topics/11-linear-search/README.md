# Linear search

**Purpose and use:** Linear search scans values until a match; it works on unsorted inputs in O(n) time.

## Understand the project

This project contains a complete, small implementation of **Linear search** in `main.py`. Trace the data structure or algorithm, inspect its output, then alter the input to test the edge cases in the practice task.

python 13-data-structures-algorithms/topics/11-linear-search/main.py
