# Merge sort

**Purpose and use:** Merge sort divides and merges sorted halves in O(n log n), using O(n) auxiliary space.

## Understand the project

This project contains a complete, small implementation of **Merge sort** in `main.py`. Trace the data structure or algorithm, inspect its output, then alter the input to test the edge cases in the practice task.

## Run

```bash
python 13-data-structures-algorithms/topics/19-merge-sort/main.py
```

Core Python only.
