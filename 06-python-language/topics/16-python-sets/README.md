# Python sets

**Purpose and use:** Sets store unique hashable values and support fast membership and set operations. Their order is not a data contract.

## Project walkthrough

This folder is a self-contained project for **Python sets**. Open `main.py` and trace each statement from its input to its result. The example uses small values so you can edit them and observe how the concept behaves.

## Run

From the repository root:

```bash
python 06-python-language/topics/16-python-sets/main.py
```

## Practice

Predict the result, change one input, rerun the project, and explain the difference. Add one boundary or invalid-input case before moving to the next topic.
