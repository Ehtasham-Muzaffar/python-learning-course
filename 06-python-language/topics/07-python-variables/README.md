# Python variables

**Purpose and use:** Variables bind descriptive names to values, making code easier to understand and update.

## Project walkthrough

This folder is a self-contained project for **Python variables**. Open `main.py` and trace each statement from its input to its result. The example uses small values so you can edit them and observe how the concept behaves.

## Run

From the repository root:

```bash
python 06-python-language/topics/07-python-variables/main.py
```

## Practice

Predict the result, change one input, rerun the project, and explain the difference. Add one boundary or invalid-input case before moving to the next topic.
