# Phase 2: Data Manipulation and Analysis

**Goal:** Turn raw tabular and numerical data into trustworthy features and summaries.

These lessons introduce NumPy arrays and Pandas DataFrames before building practical cleaning and vectorized feature-preparation workflows.

## Learning path

1. [Work with NumPy arrays](01-numpy-arrays/README.md) · [Script](01-numpy-arrays/lesson.py)
2. [Select and aggregate Pandas DataFrames](02-pandas-dataframes/README.md) · [Script](02-pandas-dataframes/lesson.py)
3. [Clean missing, duplicated, and mistyped data](03-data-cleaning/README.md) · [Script](03-data-cleaning/lesson.py)
4. [Vectorize operations and prepare features](04-vectorization-and-feature-prep/README.md) · [Script](04-vectorization-and-feature-prep/lesson.py)

**Finish line:** You can inspect, clean, summarize, and transform data without hiding assumptions in opaque steps.
