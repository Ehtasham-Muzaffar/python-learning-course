# Python classes and objects

**Purpose and use:** A class defines a type, and each object stores its own instance state.

## Project walkthrough

This folder is a self-contained project for **Python classes and objects**. Open `main.py` and trace each statement from its input to its result. The example uses small values so you can edit them and observe how the concept behaves.

## Run

From the repository root:

```bash
python 07-python-oop/topics/02-python-classes-and-objects/main.py
```

## Practice

Predict the result, change one input, rerun the project, and explain the difference. Add one boundary or invalid-input case before moving to the next topic.
