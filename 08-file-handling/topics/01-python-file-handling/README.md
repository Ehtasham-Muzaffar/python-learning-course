# Python file handling

**Purpose and use:** Use context managers to guarantee file closure and explicit encodings for text files.

## Project walkthrough

This folder is a self-contained project for **Python file handling**. Open `main.py` and trace each statement from its input to its result. The example uses small values so you can edit them and observe how the concept behaves.

## Run

From the repository root:

```bash
python 08-file-handling/topics/01-python-file-handling/main.py
```

## Practice

Predict the result, change one input, rerun the project, and explain the difference. Add one boundary or invalid-input case before moving to the next topic.
