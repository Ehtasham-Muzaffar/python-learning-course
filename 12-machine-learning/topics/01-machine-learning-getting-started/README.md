# Machine learning getting started

**Purpose and use:** Machine learning estimates patterns from examples. Define a target, a baseline, and an evaluation plan before fitting a model.

## Project walkthrough

This mini-project focuses on **Machine learning getting started**. Read `main.py` from top to bottom: identify the input, the transformation or plot, and the output. Change one example value and rerun it to check your understanding.

## Run

From the repository root:

```bash
python 12-machine-learning/topics/01-machine-learning-getting-started/main.py
```

Install core requirements with `python -m pip install -r requirements.txt`.

## Practice

Predict the result before running the code. Then change the input and explain the new output, including one limitation of the technique.
