# Python iterators

**Purpose and use:** Iterators produce values on demand, which can reduce memory use for large or streaming inputs.

## Project walkthrough

This folder is a self-contained project for **Python iterators**. Open `main.py` and trace each statement from its input to its result. The example uses small values so you can edit them and observe how the concept behaves.

## Run

From the repository root:

```bash
python 06-python-language/topics/25-python-iterators/main.py
```
