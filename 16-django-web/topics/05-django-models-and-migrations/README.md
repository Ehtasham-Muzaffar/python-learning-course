# Django models and migrations

**Purpose and use:** Models describe persistent entities; reviewed migrations evolve the relational schema reproducibly. This mini-project creates an in-memory table explicitly for learning.

## Project walkthrough

This is a complete runnable Django example. The project uses explicit, in-memory development settings so it can demonstrate **Django models and migrations** without requiring a deployed site or real database. Read each statement, change a safe input, and inspect the response or validation result.

## Run

Install the optional Django dependency and run from the repository root:

```bash
python 16-django-web/topics/05-django-models-and-migrations/main.py
```

## Practice

Extend the example with a small automated test. Keep secrets in environment/deployment configuration and do not expose Django's development server to the public internet.
