# Python range

**Purpose and use:** `range` generates an integer sequence without storing every integer in advance. Its stop value is excluded.

## Project walkthrough

This folder is a self-contained project for **Python range**. Open `main.py` and trace each statement from its input to its result. The example uses small values so you can edit them and observe how the concept behaves.

## Run

From the repository root:

```bash
python 06-python-language/topics/23-python-range/main.py
```

## Practice

Predict the result, change one input, rerun the project, and explain the difference. Add one boundary or invalid-input case before moving to the next topic.
