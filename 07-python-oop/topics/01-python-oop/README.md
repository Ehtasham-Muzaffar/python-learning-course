# Python OOP

**Purpose and use:** Object-oriented programming groups related state and behavior. Prefer simple functions unless an object boundary clarifies the domain.

## Project walkthrough

This folder is a self-contained project for **Python OOP**. Open `main.py` and trace each statement from its input to its result. The example uses small values so you can edit them and observe how the concept behaves.

## Run

From the repository root:

```bash
python 07-python-oop/topics/01-python-oop/main.py
```

## Practice

Predict the result, change one input, rerun the project, and explain the difference. Add one boundary or invalid-input case before moving to the next topic.
