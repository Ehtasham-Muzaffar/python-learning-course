# Python random module

**Purpose and use:** Pseudo-random values support simulations and sampling. A fixed seed makes examples repeatable; do not use `random` for secrets.

## Project walkthrough

This folder is a self-contained project for **Python random module**. Open `main.py` and trace each statement from its input to its result. The example uses small values so you can edit them and observe how the concept behaves.

## Run

From the repository root:

```bash
python 09-python-modules/topics/03-python-random-module/main.py
```
