# Python class properties

**Purpose and use:** Properties expose computed values or validated assignments with attribute syntax.

## Project walkthrough

This folder is a self-contained project for **Python class properties**. Open `main.py` and trace each statement from its input to its result. The example uses small values so you can edit them and observe how the concept behaves.

## Run

From the repository root:

```bash
python 07-python-oop/topics/05-python-class-properties/main.py
```

## Practice
