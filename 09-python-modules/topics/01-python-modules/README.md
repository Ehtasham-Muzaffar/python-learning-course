# Python modules

**Purpose and use:** Import functions and types from modules to reuse code and make dependencies visible.

## Project walkthrough

This folder is a self-contained project for **Python modules**. Open `main.py` and trace each statement from its input to its result. The example uses small values so you can edit them and observe how the concept behaves.

## Run

From the repository root:

```bash
python 09-python-modules/topics/01-python-modules/main.py
```

## Practice

Predict the result, change one input, rerun the project, and explain the difference. Add one boundary or invalid-input case before moving to the next topic.
