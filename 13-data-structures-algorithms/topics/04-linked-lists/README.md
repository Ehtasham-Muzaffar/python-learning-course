# Linked lists

**Purpose and use:** A linked list connects nodes with references and teaches pointer-style insertion; Python lists or deques are usually better in application code.

## Understand the project

This project contains a complete, small implementation of **Linked lists** in `main.py`. Trace the data structure or algorithm, inspect its output, then alter the input to test the edge cases in the practice task.

## Run

```bash
python 13-data-structures-algorithms/topics/04-linked-lists/main.py
```

Core Python only.
