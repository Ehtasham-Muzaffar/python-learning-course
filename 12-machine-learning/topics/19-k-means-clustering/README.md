# K-means clustering

**Purpose and use:** K-Means groups points around a chosen number of centroids. Scale meaningful features and assess stability rather than treating groups as truth.

## Project walkthrough

This mini-project focuses on **K-means clustering**. Read `main.py` from top to bottom: identify the input, the transformation or plot, and the output. Change one example value and rerun it to check your understanding.

## Run

From the repository root:

```bash
python 12-machine-learning/topics/19-k-means-clustering/main.py
```

Install core requirements with `python -m pip install -r requirements.txt`.
