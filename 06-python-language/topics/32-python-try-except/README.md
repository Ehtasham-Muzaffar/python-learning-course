# Python try except

**Purpose and use:** Handle expected errors at input or I/O boundaries with narrow exception types; do not silently hide unrelated failures.

## Project walkthrough

This folder is a self-contained project for **Python try except**. Open `main.py` and trace each statement from its input to its result. The example uses small values so you can edit them and observe how the concept behaves.

## Run

From the repository root:

```bash
python 06-python-language/topics/32-python-try-except/main.py
```

## Practice

Predict the result, change one input, rerun the project, and explain the difference. Add one boundary or invalid-input case before moving to the next topic.
