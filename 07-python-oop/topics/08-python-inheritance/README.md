# Python inheritance

**Purpose and use:** Inheritance models a substitutable is-a relationship. Use composition when objects only share a small helper operation.

## Project walkthrough

This folder is a self-contained project for **Python inheritance**. Open `main.py` and trace each statement from its input to its result. The example uses small values so you can edit them and observe how the concept behaves.

## Run

From the repository root:

```bash
python 07-python-oop/topics/08-python-inheritance/main.py
```

## Practice

Predict the result, change one input, rerun the project, and explain the difference. Add one boundary or invalid-input case before moving to the next topic.
