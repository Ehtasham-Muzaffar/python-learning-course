# Python delete files

**Purpose and use:** Delete only a specific, verified file path. Avoid recursive or user-derived deletion targets.

## Project walkthrough

This folder is a self-contained project for **Python delete files**. Open `main.py` and trace each statement from its input to its result. The example uses small values so you can edit them and observe how the concept behaves.

## Run

From the repository root:

```bash
python 08-file-handling/topics/04-python-delete-files/main.py
```
