# Python encapsulation

**Purpose and use:** Encapsulation keeps operations and valid state behind a clear interface. A leading underscore is a convention, not a security boundary.

## Project walkthrough

This folder is a self-contained project for **Python encapsulation**. Open `main.py` and trace each statement from its input to its result. The example uses small values so you can edit them and observe how the concept behaves.

## Run

From the repository root:

```bash
python 07-python-oop/topics/10-python-encapsulation/main.py
```

## Practice

Predict the result, change one input, rerun the project, and explain the difference. Add one boundary or invalid-input case before moving to the next topic.
