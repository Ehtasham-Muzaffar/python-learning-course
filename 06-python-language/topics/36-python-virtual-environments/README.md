# Python virtual environments

**Purpose and use:** A virtual environment isolates project packages. Activate it before installing dependencies or running the course.

## Project walkthrough

This folder is a self-contained project for **Python virtual environments**. Open `main.py` and trace each statement from its input to its result. The example uses small values so you can edit them and observe how the concept behaves.

## Run

From the repository root:

```bash
python 06-python-language/topics/36-python-virtual-environments/main.py
```

## Practice

Predict the result, change one input, rerun the project, and explain the difference. Add one boundary or invalid-input case before moving to the next topic.
